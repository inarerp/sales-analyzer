02

ارفع ملف/ملفات المبيعات

⬆
اسحب الملف هنا أو اضغط للاختيار
الصيغ المدعومة: CSV، XLSX — الأعمدة المطلوبة: Transaction Date, SKUs, Title, Net Proceeds, Transaction Type

نوع التحليل الحالي: المبيعات — Order فقط (لا تُحتسب المرتجعات أو الرسوم أو أي معاملات أخرى ضمن هذه النتيجة).

الملف الأول — ملف ربط المنتجات (Business Report)

يُستخدم لربط SKU بالـChild ASIN. الأعمدة المطلوبة: SKU، ASIN (المنتج الفرعي).

⬆
اسحب ملف Business Report هنا أو اضغط للاختيار
CSV أو XLSX

الملف الثاني — ملف المبيعات (Custom Transaction Report)

يحتوي على date/time، sku، quantity، وproduct sales. يتم اكتشاف صف العناوين تلقائيًا حتى لو سبقته أسطر Metadata.

⬆
اسحب ملف Custom Transaction هنا أو اضغط للاختيار
CSV أو XLSX

يمكنك رفع أكثر من ملف (مثلاً أبريل + مايو، ثم يونيو + يوليو) — سيتم دمج كل صفوف الملفات وتحليلها كتقرير واحد.

⬆
اسحب ملف أو أكثر من ملفات Trendyol هنا أو اضغط للاختيار
الأعمدة المطلوبة: Model code, Product name, Net items sold, Net sales, Discount amount (وتُعرض Barcode, Category, Brand تلقائيًا إن وُجدت في الملف)
