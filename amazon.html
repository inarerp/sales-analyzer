نوع التحليل الحالي: المبيعات — Order فقط (لا تُحتسب المرتجعات أو الرسوم أو أي معاملات أخرى ضمن هذه النتيجة).

الملف الأول — ملف ربط المنتجات (Business Report)

يُستخدم لربط SKU بالـ Child ASIN. الأعمدة المطلوبة: SKU، ASIN (المنتج الفرعي).

⬆
اسحب ملف Business Report هنا أو اضغط للاختيار
CSV أو XLSX

الملف الثاني — ملف المبيعات (Custom Transaction Report)

يحتوي على date/time، sku، quantity، و product sales. يتم اكتشاف صف العناوين تلقائيًا حتى لو سبقته أسطر Metadata.

⬆
اسحب ملف Custom Transaction هنا أو اضغط للاختيار
CSV أو XLSX
